# Zafiro - Stock y Ventas para Windows

## Descargar

**[Descargar Zafiro para Windows](https://github.com/pablomanchon/zafiro-releases/releases/latest/download/Zafiro-Setup.exe)**

Este link siempre descarga la última versión.

## Instalar

1. Abrí `Zafiro-Setup.exe`.
2. Si Windows muestra *"Windows protegió tu PC"*, hacé clic en **Más información** y después en **Ejecutar de todas formas**. Aparece porque la app es nueva y todavía no tiene reputación en Microsoft; no significa que tenga un virus.
3. Seguí los pasos del instalador. No hace falta ser administrador.

## Actualizaciones

La app se actualiza sola: cuando hay una versión nueva, la descarga y te ofrece reiniciar para instalarla.

También podés usar Zafiro desde el navegador: <https://zafiro-gestion-comercios.vercel.app/>
